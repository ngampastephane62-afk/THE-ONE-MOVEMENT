PART D — NEWS TYPES + LOCAL DATA
Create artifacts/web/src/lib/news-data.ts exporting a typed NewsArticle[] and helpers. Article shape:
- slug (string, unique)
- title (string)
- subtitle (string, optional)
- category (NewsCategorySlug)
- authorType (NewsAuthorType)
- authorDisplayName (string)
- authorEntitySlug (string, optional — links to a future partners-data entry; not validated cross-package here to avoid coupling, but MUST match a partners-data slug if present; if authorEntitySlug is set and no matching PartnerEntity exists yet, the byline still renders using authorDisplayName only — no error, no broken link)
- publishedAt (ISO date string)
- updatedAt (ISO date string, optional)
- heroMediaSlot (string, optional — dev label, PhotoSlot pattern; NEVER a real image path)
- excerpt (string, ≤200 chars)
- body (structured JSON blocks — see BLOCK TYPES below)
- programSlugs (string[], optional — validated against PROGRAM_SLUGS at build/render time)
- sectorSlugs (string[], optional — validated against SECTOR_SLUGS)
- relatedArticleSlugs (string[], optional — explicit editorial choices, never algorithmic)
- seoTitle (string)
- seoDescription (string, ≤160 chars)
- editorialStatus (EditorialStatus) — HARD RENDER GATE
- sourceUrl (string, optional — for republished media-partner pieces; must pass isSafeUrl() — http(s) only, no javascript:/data:/malformed; if present, article rendering shows an attribution line linking back to sourceUrl and does NOT reproduce the full external body — see BODY RULE below)
- licensing (string, optional — internal reference for republishing rights; NEVER rendered)
- consentReferences (string, optional — internal reference for named-individual consent, NEVER rendered)

BLOCK TYPES (structured content — safe to render, portable to future CMS):
- { type: "paragraph", content: string }
- { type: "heading", level: 2 | 3, content: string }
- { type: "quote", content: string, attribution?: string }
- { type: "list", ordered: boolean, items: string[] }
- { type: "image", altText: string, mediaSlot: string, caption?: string }   // mediaSlot is a dev label; no real image loaded at launch — renders as PhotoSlot-style placeholder
- { type: "embed", provider: "youtube", refId: string }   // RESERVED but disabled at launch — renderer returns a placeholder card explaining video governance pending; do NOT fetch, iframe, or hotlink
NO raw HTML anywhere. NO dangerouslySetInnerHTML. Any string content is rendered as text.

BODY RULE for republished third-party pieces (sourceUrl present):
- Do NOT reproduce the full original body — even in blocks — unless licensing indicates explicit republishing rights and an editor has approved that specific piece for full republishing.
- Default behavior when sourceUrl is present: render whatever body blocks exist (which will be editor-written summary paragraphs), followed by a prominent attribution block linking to sourceUrl with wording "Read the original at [domain]".
- This is enforced by CONVENTION and RENDER PATTERN, not by field validation — document it in the file header and in the editorial policy section on /news.

Initial data: EMPTY ARRAY. The shell must be composed and honest with zero articles. Do not populate any sample article, do not commit any "hello world" post.

Export helpers:
- getPublishedArticles() → filters to editorialStatus === PUBLIC_EDITORIAL_STATUS, sorted by publishedAt DESC. This is the ONLY function pages use to read articles.
- getPublishedArticleBySlug(slug) → returns a published article or undefined. Unknown/unpublished slugs return undefined.
- getPublishedArticlesByCategory(slug) → filtered by category, then published gate.
- getRelatedPublishedArticles(article) → resolves article.relatedArticleSlugs, filters to published, preserves editorial order, caps at 3.
- isSafeUrl(url) → same implementation pattern as partners-data (http(s) only, no javascript:/data:/malformed) — do NOT import from partners-data; duplicate the small helper locally to keep the modules independent, and note the duplication in a comment as an intentional Phase 2 refactor target.
