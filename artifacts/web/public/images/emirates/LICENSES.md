## Cartography and world artwork

The UAE outline is derived from Natural Earth 1:10m Admin 0 countries, public
domain: https://www.naturalearthdata.com/about/terms-of-use/
Simplified from the upstream GeoJSON; marker positions represent capital cities.
It is not an emirate administrative-boundary data set.

The world artwork is separately supplied by the TOMI Founder and already used by
this project. The Commons licence above applies only to the two named photos,
not the whole website or the Founder artwork.
