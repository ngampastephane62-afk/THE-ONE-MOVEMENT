PROJECT CONTEXT

THE ONE MOVEMENT INTERNATIONAL — a permanent global ecosystem connecting culture, business, investment, diplomacy, innovation, education, tourism, media and humanitarian impact. Not an event website; The One Fashion Week International is one program within it. Slogan: "ONE WORLD. ONE PURPOSE. ONE MOVEMENT." Bilingual signature: "WE ARE ONE / نحن واحد".

Stage 0 (foundation, routing, placeholder pages, database) is complete and must not be disturbed. THIS STAGE: THE DESIGN SYSTEM. No real pages are built in this stage.

CURRENT TASK

Create the complete visual design system as reusable tokens and components, plus a single internal gallery page at route /design-system displaying every token and component for review.

DESIGN DIRECTION — "GLOBAL GOLD"

This must feel like a landmark institution with creative fire — think of the confidence of a world-class museum combined with the warmth of a cultural festival. Premium, cinematic, alive. It must NOT look like a template, a corporate SaaS site, or a generic event page.

COLOR SYSTEM (define as tokens, 3–4 steps each):
- Ink: deep near-black warm bronze family (base around #16100A–#1A120B) — primary dark surfaces.
- Gold: rich warm gold (core around #C9A24B) with a BRIGHT living highlight step (around #F0CE83) used for glowing accents on dark surfaces — this bright step is what keeps dark screens vibrant instead of muddy.
- Ivory: warm light family (around #F7F1E5) for reading surfaces.
- Sand: muted desert mid-tone for secondary surfaces and subtle fills.
- One deep accent for contrast moments: a profound warm crimson-earth tone (around #7A2E2E family) usable ONLY in small doses (tags, data accents) so the system is not monochrome.
- Reserved token "program-fashionweek" teal (#3E8FA3 family) — defined but NOT used in any default component.
Document accessible pairings: body text always ink-on-ivory or ivory-on-ink; gold text only at large sizes or in its darkened step.

TYPOGRAPHY — THE MAIN CHARACTER:
- Display face: geometric, architectural, slightly art-deco confidence. Evaluate Marcellus, Cinzel, and Josefin Sans; pick ONE and justify. Display sizes must be OVERSIZED and confident: define a "display-xl" of roughly clamp(3.5rem, 8vw, 7rem) with tight line-height for hero statements, down through display-lg and display-md. Generous letter-spacing on uppercase display text.
- Body: IBM Plex Sans + IBM Plex Sans Arabic (preferred) or Noto Sans + Noto Sans Arabic. Full Arabic support required; RTL must not break (avoid hard-coded left/right that would fail under dir="rtl"; no translations needed now).
- Scale: display-xl/lg/md, h1–h4, body-lg, body, small, caption, and an "eyebrow" style (small, uppercase, letterspaced, gold) used above headings.

SIGNATURE MOTIFS (the ownable elements — used with restraint, max one per screen region):
1. GOLD THREAD: a thin gold line component that can run horizontally OR vertically, with an optional small node/dot — this is the brand's "connection" symbol and will later animate through the ecosystem page. Build it as a component with a subtle shimmer-on-scroll-into-view animation (CSS only, disabled under reduced motion).
2. RADIANT SURFACE: a dark hero container with a soft radial gold glow rising from bottom or behind content (pure CSS gradients, layered, subtle noise-free) — cinematic, never busy.
3. GEOMETRIC ACCENT: one optional decorative border-pattern strip component inspired by woven geometric patterns, rendered as elegant thin-line SVG (not literal ethnic print), off by default.
4. DUOTONE IMAGE TREATMENT: define a CSS utility that renders images in an ink+gold duotone with a hover/reveal to full color — no images added now, but the utility ships ready for Stage 2.

COMPOSITION RULES (bake into gallery examples):
- Asymmetry is default: section examples must show off-center layouts (e.g., heading left-aligned at large scale with content offset), NOT everything centered.
- Scale contrast: pair one enormous element with small quiet ones.
- Space is luxury: generous vertical rhythm tokens (section spacing steps).

BANNED CLICHÉS (do not produce): purple/blue gradients, glassmorphism/frosted cards, neon glows, identical rounded corners on everything (define at least two radius personalities: sharp 0–2px for institutional elements, soft for interactive), thin grey hairline borders everywhere, centered-everything layouts, drop shadows as the main depth device (prefer color/surface shifts).
