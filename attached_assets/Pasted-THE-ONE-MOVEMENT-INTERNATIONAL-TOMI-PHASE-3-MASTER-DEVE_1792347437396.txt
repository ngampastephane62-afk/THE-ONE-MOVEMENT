====================================================

====================================================

THE ONE MOVEMENT INTERNATIONAL is not
an ordinary website.

It is not simply a social network.

It is not a subscription platform.

It is a GLOBAL UNIVERSE connecting
humanity through:

PEACE
UNITY
CULTURE
CREATIVITY
DIVERSITY
TOLERANCE
INCLUSION
INNOVATION
OPPORTUNITY
HUMANITARIAN IMPACT

The platform represents people from
different nations, cultures, languages,
professions and generations.

Artists, designers, musicians, filmmakers,
entrepreneurs, investors, diplomats,
humanitarian leaders, innovators,
creators and peace ambassadors
belong to the same global movement.

THE CORE MESSAGE:

"YOU DON'T JUST JOIN A PLATFORM.
YOU BECOME PART OF A GLOBAL MISSION."

The experience must communicate this
vision immediately.

====================================================
II. THE CREATIVE DIRECTION
====================================================

DESIGN PHILOSOPHY:

GLOBAL.
CULTURAL.
IMMERSIVE.
ARTISTIC.
HUMAN.
FUTURISTIC.
PREMIUM.
ELEGANT.

The website must feel like a living
international cultural universe.

NOT a generic SaaS dashboard.

NOT a standard social media clone.

NOT a conventional corporate website.

NOT a collection of repetitive cards.

Create a distinctive visual language.

The result should feel comparable in
craftsmanship to a premium digital
cultural exhibition or international
creative institution.

Preserve TOMI's existing brand identity
and recognizable visual assets.

Do not arbitrarily replace existing
logos, colors, fonts or imagery.

Build upon the established identity.

====================================================
III. IMMERSIVE VISUAL LANGUAGE
====================================================

Create a coherent visual system using:

- Sophisticated typography
- Cinematic composition
- Carefully controlled motion
- Elegant transitions
- Layered imagery
- Cultural motifs
- Artistic textures
- Depth and atmospheric lighting
- Editorial storytelling
- Responsive visual compositions
- Refined interactive details

Introduce cultural patterns and
artistic motifs inspired by the
diversity of world cultures.

IMPORTANT:

Do not reduce Africa or any other
region to stereotypes.

Avoid generic tribal patterns,
random flags and superficial
cultural decorations.

Cultural inspiration must be
respectful, contemporary and
international.

Use authentic imagery and
existing licensed assets.

If a visual asset is unavailable,
create a clearly identified
replaceable visual placeholder.

Do not invent real ambassadors,
partnerships, institutions or events.

====================================================
IV. THE GLOBAL WORLD EXPERIENCE
====================================================

Design an immersive visual concept
representing global connection.

Possible elements:

- A sophisticated animated globe
- Interconnected cultural regions
- Elegant light trails
- International creative networks
- Moving geographic compositions
- Human-centered imagery
- Subtle atmospheric particles
- Visual representations of unity

The globe must be meaningful,
not merely decorative.

It should represent connection
between people and cultures.

Do not imply that real members
are located in particular places
unless verified public data exists.

Use illustrative visualizations
when real data is unavailable.

Avoid heavy animations that damage
mobile performance.

====================================================
X. MOTION AND SCROLL EXPERIENCE
====================================================

Motion is a core part of
the TOMI digital identity.

Create tasteful animations:

- Scroll-based reveals
- Layered transitions
- Text reveals
- Image transitions
- Cinematic section entrances
- Hover interactions
- Smooth visual continuity
- Subtle depth effects

Motion must enhance storytelling.

Avoid excessive movement,
unnecessary loading screens,
or animations that obstruct content.

Respect prefers-reduced-motion.

Do not break the existing
navigation and scroll fixes.

Preserve browser back/forward
behavior and anchor navigation.

====================================================
XI. MOBILE EXPERIENCE
====================================================

Mobile is a first-class priority.

The experience must be
visually impressive on:

- iPhone
- Android
- Tablets
- Desktop

Optimize:

- Responsive typography
- Touch interactions
- Navigation
- Media loading
- Animation performance
- Layout stability
- Readability
- Accessibility

Avoid large videos or WebGL
effects that make mobile
devices slow or unstable.

Provide elegant static
fallbacks where appropriate.

====================================================
XII. PERFORMANCE AND ACCESSIBILITY
====================================================

Maintain:

- Semantic HTML
- Keyboard navigation
- Sufficient contrast
- Accessible controls
- Responsive images
- Lazy loading
- Reduced-motion support
- Efficient rendering

Avoid unnecessary dependencies.

Prefer existing project tools
and design libraries.

Do not add large animation
frameworks unless strictly necessary.

Do not sacrifice usability
for visual spectacle.
