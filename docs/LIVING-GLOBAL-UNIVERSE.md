# TOMI — Living Global Universe

## Authorization

The comprehensive frontend directive supersedes the earlier Real Estate-only
pilot scope. Existing sector URLs, programmes, community, enquiry and member
routes remain the product foundation. No new backend, authentication, database,
payment, publishing permission or production operation is authorized.

## Presentation contracts

- Seventeen worlds use one configuration-driven visual layer; Real Estate retains
  its richer authored pilot. Professional roles and learning topics are editorial,
  never invented member records, courses or certifications.
- Discovery matches a local index of actual sectors, programmes and pages. It
  does not search private profiles, save interests or make external AI requests.
- TOMI AI is guided navigation with fixed responses, explicitly not an AI service.
- The One Key is a future optional concept, not a purchasable entitlement.
  Public exploration and ordinary community belonging remain free.
- Creative Space is a reviewed-contribution concept, not a public upload service.
- Connected brands keep distinct identities and commercial journeys. A navigation
  concept is not evidence of shared legal ownership.
- Editorial coverage, documented partners and sponsored placements must remain
  distinct. A coverage attribution does not create a sponsorship or endorsement.

## Future Founder Command Center

Extend the existing administration system only under separate authorization.
Prefer a structured editor of allowlisted content blocks over arbitrary HTML,
scripts or drag-and-drop executable layouts. Reuse the validation, private assets,
immutable versions, optimistic concurrency, preview and explicit publication
architecture in [17-WORLDS-ARCHITECTURE.md](17-WORLDS-ARCHITECTURE.md#6-the-one-creative-studio--architecture-proposal-only).

Suggested approved block types:

| Block | Allowed edits | Review boundary |
| --- | --- | --- |
| World introduction | Approved text, existing motif preset, licensed asset reference | Sector identity and routes remain stable |
| Cultural chapter | Text, source, caption, approved archive reference | Historical and cultural accuracy |
| Partner placement | Existing organization reference, approved label and display period | Evidence of relationship; sponsorship never implies verification |
| Press article | Existing coverage reference, publisher credit and known original link | No false attribution or invented URL |
| Brand navigation | Approved identity and verified destination | No legal or payment-flow consolidation |
| Creative contribution | Approved submission reference and attribution | Consent, rights and editorial acceptance before publication |

Separate edit, review and publication capabilities must be approved and enforced
server-side in a future phase, not inferred from a frontend button. Preview must
not expose drafts; publishing content must not deploy application code.

## Verification boundary

Isolated component/event checks and TypeScript/build checks cannot establish real
device sharing, clipboard permission behavior, authenticated access, cultural asset
licensing beyond the existing archive, production availability or release readiness.
No production readiness claim or deployment is part of this delivery.

## Delivery — implemented

- Pages: Ecosystem; compact discovery entry on the active Home experience; Thanks
  World, Thanks Emirates, Documentary; News and partner history; decorative identity
  alignment on member Welcome, People, Profile and Workspace.
- Worlds: Fashion, Music, Dance, Film, Art, Business, Investment, Tourism,
  Diplomacy, Innovation, Technology, NGOs, Media, Education, Real Estate,
  Health & Care, Humanitarian Action.
- Shared sector chapters, original illustrative motifs, real programme/resource
  links, local directory filtering and existing safe sharing controls. Real Estate
  retains its authored pilot and gains opportunities/directory/share pathways.
- Lightweight entrances, motif movement, progressively enhanced CSS scroll
  transitions, pause and reduced-motion support. Scroll-linked headings never
  depend on opacity to remain readable.
- Distinct cultural lenses for African/global creativity and UAE architecture,
  hospitality and innovation; documentary timeline reuses published edition dates,
  explicitly not film release dates. Dubai stays in development.
- Local discovery and TOMI AI fixed-answer guide; future One Key and Creative Space;
  four connected-brand concepts, with OYE explicitly lacking an active destination.
- Editorial/partner/sponsored label component, applied only to existing coverage
  and documented partner history. No sponsored placement is invented.

## Tested in isolation

All **93 frontend tests passed**, including 11 Living Universe tests. Coverage
includes seventeen configurations, actual routes/resources, all five Founder
search examples, search recovery, guide selection, directory filtering/focus,
share/copy/cancellation branches and existing member/privacy/messaging invariants.
TypeScript, Vite build and whitespace checks passed. No backend test or restart.

Mobile corrections constrain long public-directory text to its card, explicitly
define the pilot's shared accent, and keep chapter headings readable. A fresh
390-pixel-wide full-page capture remains 390 pixels wide after the correction
(previously 659). Cropped lower-page screenshots show the Real Estate opportunity
and professions chapters plus the directory. Desktop crops show Music's hero,
chapters, discovery and TOMI AI. These are static visual observations, not clicks.

Only the web workflow was restarted and confirmed running. Existing build warnings
remain: tooltip sourcemap diagnostic and a large main JS chunk, approximately
2.06 MB / 577 KB gzip. No dependency was added.

## Not verified in browser / remaining limitations

- Native sharing, clipboard permission errors and keyboard flows on actual
  iPhone/Android browsers; tablet layouts and all seventeen worlds visually.
- Authenticated member pages: presentation-only changes were inspected in source
  and isolated tests, not a signed-in browser session.
- New copy has not been validated in all seven languages.
- World artwork is explicitly illustrative. Sector-specific cleared documentary
  photography remains a future asset dependency, not a claim of photographic
  implementation. No external image generation or AI calls were used.
- Real AI, Key services, uploads, CMS and Founder publishing controls remain future
  dependencies and were not activated. No production readiness claim is made.
